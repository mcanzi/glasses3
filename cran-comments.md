## Notes

'Tobii Pro Glasses 3' and 'Tobii Pro Lab' are the names of the eye tracker and of
the manufacturer's analysis software. The package reads the files the eye tracker
writes and does not use or include any Tobii software. The README and the package
help page state that the package is not affiliated with Tobii.

The example recording in inst/extdata is 30 seconds of a recording made with the
glasses, with identifying metadata replaced by placeholders.
