# Path to the example recording

The package includes the first 30 seconds of a Glasses 3 recording at 50
Hz. The scene video is left out, and the participant name, serial
numbers, recording ID and start time are replaced with placeholders.

## Usage

``` r
g3_example()
```

## Value

Path to the example recording folder.

## Examples

``` r
g3_example()
#> [1] "/home/runner/work/_temp/Library/glasses3/extdata/recording"
```
